# Visual Line Hide v3 — Top Variant Shortlist

来自 32 个 v3 变体的 `summary.csv` 初筛。

## v3 关键指标

- `core%`：核心 mask 占比
- `edit%`：核心 + halo 总编辑占比
- `dir%`：核心区中通过**方向性背景**（沿法向两侧 median）成功取到 bg 的比例；
  其余落回 v2 的 side-band gaussian bg
- `rm_core`：核心区平均 `|raw - suppressed|`
- `rm_halo`：halo 区平均 `|raw - suppressed|`
- `resid` = `core_residual_after_suppress`：核心区在抑制后相对 `bg_low` 还残留
  多少 darkness。**`resid` 越接近 0，黑线越彻底融入背景**；正值 = 略亮于
  bg_low；负值 = 仍偏暗（line 没完全压平）

> v3 的目标就是把 `|resid|` 拉到 0 附近——这是 v1/v2 没有的指标。

## 关键观察

1. **`#1 / #2` 把 resid 干到 +0.50** —— 核心几乎完全融入 `bg_low`。
   差异：`kh0.2`（#2）把 halo 也压得更狠（halo 残留更少），`kh0.3`（#1）更柔和。
2. **`bt=1.0` + `wc=7` + `h=6`** 是最佳组合：`bt=1.0` 让核心严格只取真黑线、
   `wc=7` 覆盖较粗的线、`h=6` halo 不过宽。
3. **越激进的 mask（D85b、bt=0.5），dir% 越低** —— 编辑区变大意味着法向采样
   更容易撞到其它编辑像素，落回 side-band fallback 更多，resid 也更负。
4. **#5 / #6** 是 "尽量多覆盖线" 的极端方案；如果担心 #1 漏了某些细线/短线，
   可以参考这两个。

## 怎么挑

- **默认主推 #1** (`C90b_bt1.0_wc7_h6_kh0.3`) ——
  视觉黑线 + halo 处理最干净，编辑区适中。
- 看 `zoom_compare_sheet.jpg` 比较 5 行 zoom 缩略图，**特别看 Z2/Z3 是否
  还有贯穿黑线**——v2 review 中这些区域是 v3 的主要靶点。
- 如果 #1 漏掉某些线、希望更广覆盖：用 #5 (`bt=0.5, wc=7, h=8`)。
- 如果担心 D85b 的 mask 不准、想保守一些：避开 #6/#7。
